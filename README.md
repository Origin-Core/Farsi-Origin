## 🎮 درباره پروژه
**فارسی اوریجین (Farsi-Origin)** یک رابط کاربری (Frontend) کاملاً پویا است که مستقیماً به API گیت‌هاب متصل می‌شود. این یعنی برای مدیریت محصولات سایت (فارسی‌سازها)، نیازی به پنل مدیریت یا دیتابیس پیچیده ندارید! کافیست فایل‌ها را در همین مخزن آپلود کنید تا سایت به‌صورت خودکار آن‌ها را شناسایی کرده و برای کاربران نمایش دهد.

### ✨ ویژگی‌های کلیدی:
- ⚡ **بدون نیاز به بک‌اند (Serverless):** استفاده از GitHub API برای خواندن فایل‌ها.
- 🎨 **طراحی مدرن و واکنش‌گرا:** رابط کاربری گرافیکی با انیمیشن‌های نرم (Smooth Animations).
- 💎 **پشتیبانی از محصولات رایگان و پولی:** تفکیک هوشمند محصولات تنها با تغییر نام فایل.
- 🌙 **تم تاریک گیمینگ:** طراحی شده با رنگ‌های سرمه‌ای و سبز یشمی.
- 📱 **پاپ‌آپ اختصاصی (Modal):** برای هدایت کاربران به درگاه/تلگرام جهت تهیه نسخه‌های ویژه.

## ⚙️ آموزش استفاده (برای مدیران سایت)

برای اضافه کردن یک بازی جدید به سایت، کافیست فایل‌های آن را در همین مخزن (بخش کدها) آپلود کنید. سایت بر اساس نام فایل‌ها، محصول را می‌سازد.

### ۱. انتشار فارسی‌ساز رایگان 🟢
دو فایل با نام **دقیقاً یکسان** (یکی عکس و یکی فایل فشرده) آپلود کنید:
- `Spider-Man.zip` (یا `rar` / `7z`)
- `Spider-Man.jpg` (یا `png` / `webp`)

> **نتیجه:** سایت به صورت خودکار کاور بازی را نمایش داده و دکمه **«دانلود رایگان»** را برای آن فعال می‌کند.

### ۲. انتشار فارسی‌ساز ویژه (پولی) 🟡
کلمه `_paid` را به انتهای نام فایل‌ها (قبل از فرمت) اضافه کنید:
- `The-Last-Of-Us_paid.zip`
- `The-Last-Of-Us_paid.jpg`

> **نتیجه:** سایت به صورت خودکار روبان و دکمه را به رنگ **طلایی** درمی‌آورد و با کلیک روی **«خرید محصول»**، پاپ‌آپ اتصال به تلگرام باز می‌شود. (کلمه `_paid` در سایت به کاربران نمایش داده نمی‌شود).

### ۳. اضافه کردن توضیحات (اختیاری) 📝
اگر می‌خواهید بازی شما در سایت توضیحات داشته باشد، یک فایل متنی با همان نام اضافه کنید:
- `Spider-Man.txt` (متن داخل این فایل به عنوان توضیحات کارت بازی در سایت نمایش داده می‌شود).
